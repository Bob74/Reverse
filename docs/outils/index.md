# Outils

::: info [Memory Editors](./memory-editors/)
Les outils qui nous permettent de lire et modifier la mémoire des programmes. Spoiler : Cheat Engine est déjà tellement génial qu'il est souvent la solution à tout faire de toute manière.
:::

::: info [Disassemblers & debuggers](./disassemblers/)
Les désassembleurs et débugueurs sont des outils d'analyse et de modification du code assembleur des programmes. Ils sont utiles lorsque l'on veut analyser précisément le comportement d'un programme ou d'une fonction et que l'on veut la patcher par la suite.
:::

::: info [.Net](./dot-net/)
Les outils .Net méritent leur catégorie à eux seuls. Ils permettent de restituer le code source quasi exact d'un programme .Net et même de le patcher pour modifier son fonctionnement.
:::

::: info [Java](./java/)
Java fonctionne un peu comme le .Net (ou l'inverse si vous préférez), de ce fait il est possible de visualiser et modifier du code Java comme si on était en train de consulter le code source.
:::
